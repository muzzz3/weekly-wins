# Weekly Wins

A private, local-first desktop app for effortless work tracking and AI-generated summaries.

---

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org) 20 or later
- [Ollama](https://ollama.com) — only needed for AI summaries; the app otherwise works fine without it

  Install it:
  ```bash
  brew install ollama       # macOS
  # or download an installer for Windows/Linux from https://ollama.com/download
  ```

  Start the Ollama server (leave this running in the background — on macOS, installing via the Ollama app does this for you automatically):
  ```bash
  ollama serve
  ```

  Then, in a separate terminal, pull the two models this app uses:
  ```bash
  ollama pull llama3.2
  ollama pull mistral
  ```

### Setup
```bash
git clone https://github.com/muzzz3/weekly-wins.git
cd weekly-wins
npm install   # also rebuilds better-sqlite3 for Electron automatically
npm run dev
```

If you ever see a native module / `NODE_MODULE_VERSION` error, re-run the rebuild manually:
```bash
npx electron-rebuild -f -w better-sqlite3
```

### Restarting
`electron-vite dev` spawns Electron as a separate process, so Ctrl-C alone can leave it running in the background. To fully stop and restart:
```bash
pkill -f "weekly-wins/node_modules/electron"; pkill -f "electron-vite dev"
npm run dev
```

## The Problem

When you're deep in the work, you don't have time to maintain a status doc, update a tracker, or write a standup. Progress gets lost. Perf review season arrives and you're reconstructing months of work from memory and git history. Weekly Wins fixes this by making capture so fast it doesn't interrupt your flow.

---

## The Two Modes

### 1. Capture Bar — `⌘⇧W`
A floating input bar that appears on top of whatever you're doing. Type what you just did, hit Enter — it's logged and the bar disappears. The entire interaction takes under 5 seconds.

- Triggered by global hotkey from anywhere on the system
- Single text input — just type and hit Enter, nothing else required
- Enter to save, Escape to dismiss without saving
- Same hotkey toggles it closed if already open

### 2. Dashboard Overlay — `⌘⇧D`
A full-screen overlay that slides in over your current work. Review mode — for reflection, not data entry.

- Escape or `⌘⇧D` again to close
- Always opens to the **current week view**, with today's card highlighted
- Smooth transitions throughout — cards expand in-place, views zoom in/out

## Dashboard: Time Hierarchy

Navigation flows from macro to micro. You can zoom in and zoom out.

```
Quarter View  →  Month View  →  Week View  →  Day View (full screen)
```

### Week View (default)
- 7 day cards laid out horizontally
- Today is highlighted with a distinct border
- Each card shows: date, note count, mood average, and a one-line AI summary
- Card background color reflects productivity score (see below)
- Click any card to expand it into Day View

### Day View
- Expands from the card in-place (zoom transition) to fill the screen
- Full chronological list of notes for that day
- AI-generated daily summary at the top
- Back button / Escape collapses back to Week View

### Month View
- Calendar grid of day cards (same color coding)
- Click a day → Day View
- Aggregate week rows with weekly summary scores

### Quarter View
- 13 week-rows, each showing the week's productivity color and a one-line summary
- Gives a bird's-eye view of how the last ~3 months have gone
- Click a week row → Week View for that week

## Productivity Color Coding

Each day card is colored on a spectrum (muted red → neutral gray → muted green) based on an AI-assessed productivity score.

- **Primary signal: AI productivity score (90%)** — Ollama reads all of a day's notes holistically and returns a score (0–10) based on work completed, momentum, and blockers. The prompt: *"Based on these notes, rate how productive this day was from 0–10, considering work completed, momentum, and any blockers. Return only the number."*
- **Secondary signal: note volume (10%)** — a light tiebreaker so days with more captured context score slightly higher than equally-rated days with fewer notes
- **Formula:** `score = (aiScore / 10) * 0.9 + (normalizedVolume) * 0.1`

Days with no entries are rendered as neutral gray — unscored, not unproductive.

## AI Summaries

Summaries are generated by a local [Ollama](https://ollama.com) instance — no data leaves your machine.

### Behavior
- Summaries are generated **in the background** whenever a new note is saved
- By the time you open the dashboard, summaries are already there — no waiting
- Three summary types, generated at each level:
  - **Daily summary** — concise narrative of what you worked on
  - **Weekly summary** — themes, highlights, blockers across the week
  - **Monthly / quarterly summary** — impact-focused, perf-review language

### Prompts are tuned for two audiences
- **Standup mode** — Yesterday / Today / Blockers format, concise
- **Perf review mode** — Action verbs, impact framing, grouped by theme

### Requirements
- Ollama must be running locally: `ollama serve`
- Models used: `llama3.2` (summaries/scoring) and `mistral` (standup/perf review prose)

## Data

- All notes stored locally in SQLite (`~/Library/Application Support/weekly-wins/weekly-wins.db`)
- No network requests except to `localhost:11434` (Ollama)
- No accounts, no sync, no cloud

### Note schema
| Field | Type | Notes |
|---|---|---|
| `id` | integer | auto |
| `text` | text | the raw note |
| `tags` | text | JSON array, optional |
| `created_at` | text | ISO 8601 UTC |
